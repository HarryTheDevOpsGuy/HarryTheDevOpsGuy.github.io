# Complete Linux Shell Scripting Course

## Course Overview
This comprehensive course will take you from the basics of shell scripting to advanced concepts and real-world applications.

## Prerequisites
- Basic understanding of Linux commands
- Access to a Linux environment or MacOS terminal
- Text editor (vim, nano, or VS Code)

   - for loops
   - while loops

   - Nested loops
